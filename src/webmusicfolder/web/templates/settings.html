General

Saved on the server and kept across restarts. They override the environment values (WMF_MUSIC_DIR, WMF_QUALITY, WMF_CONCURRENCY), which stay as the defaults.

Absolute path on the server (in Docker it must be inside a mounted volume to survive container recreation). Default: . Existing files are not moved; tracks that are not found in the new folder are treated as not downloaded. Cannot change while a download runs.

YouTube audio is already compressed (about 130 to 160 kbps), so very high settings only make bigger files, not better sound. V5 or V2 is plenty; V0 and 320k can be twice the size.

Data folder (state, logs, cookies): , set with WMF_DATA_DIR.

Password

Change the password used to unlock the app. It is stored as a salted hash in the data folder and replaces WMF_PASSWORD. Other devices are signed out. To go back to WMF_PASSWORD, delete password.json from the data folder.

yt-dlp

When YouTube changes and downloads start failing, update yt-dlp here. The new version is kept in the data volume and used from the next download on; no image rebuild needed.

Installed version:

Downloading the latest release, this can take a minute.

Updates wait for an idle queue: if a download is running the button reports it and nothing changes.

Download options

Both apply to downloads that start after the change.

Cuts sponsor reads, self promotion, interaction reminders and non music parts out of the MP3 using the community SponsorBlock database. Intros and outros are kept. If the SponsorBlock service is unreachable the track is downloaded uncut.

Measures each track and stores a gain value in the file so players that support ReplayGain play everything at a similar volume. The audio itself is not changed. Tracks already in the library are not touched.

YouTube cookies

Needed for private playlists and age restricted videos. Export a cookies.txt (Netscape format) from your browser while on YouTube, for example with the "Get cookies.txt LOCALLY" extension, then upload or paste it.

These cookies give access to the Google account they came from. Use a dedicated account if you can. The file is stored on the server with mode 0600 and is never shown again or written to the logs.

Status:

Source in use:

The server reads cookies straight from the browser set in WMF_COOKIES_FROM_BROWSER (local runs only). An uploaded cookies.txt takes precedence while it exists.

Cookies expire or rotate. If downloads start asking to sign in again, export a fresh file and upload it again.
